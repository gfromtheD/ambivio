# Dirección pública

La dirección principal de Ambivio es https://ambivio-app.vercel.app.

El nombre ambivio.vercel.app estaba ocupado. El proyecto de Vercel se ha renombrado de imobiliaria a ambivio-app y el nuevo dominio está asociado al proyecto para futuros despliegues.

NEXT_PUBLIC_SITE_URL de producción y el site_url de Supabase usan la nueva dirección. Supabase también autoriza sus callbacks; las direcciones anteriores específicas se conservan para enlaces ya emitidos.
